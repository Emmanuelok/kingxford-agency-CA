# Adding a completed project

1. Add a verified, completed website to `lib/completed-projects.ts`. Use a unique URL-safe `slug`, the approved public website URL, a short factual description, disciplines and three useful project highlights.
2. Capture the actual website and place an optimized WebP preview in `public/images/projects/`. Enter the correct image dimensions and a descriptive alt text in the project record.
3. Choose the `rose` or `sage` showcase background. The project count, index and showcase are derived from the registry and update automatically.
4. Check the preview, expand the project notes and confirm that the live website link opens the intended project. Verify the page at phone and desktop widths before publishing.

Only include verified claims. Do not add made-up performance metrics, testimonials, launch dates, or untested backend functionality. New records need no page component changes.
