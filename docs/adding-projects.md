# Adding a completed project

1. Add a verified, completed website to the registry in `lib/completed-projects.ts`. Use a unique URL-safe `slug`, the approved public website URL, a short factual description, disciplines and three useful project highlights. Set `published: true` only when it should appear publicly.
2. Capture the actual website and place an optimized WebP preview in `public/images/projects/`. Enter the correct image dimensions and a descriptive alt text in the project record.
3. Choose the `rose` or `sage` showcase background. The project count, index, showcase and sharing preview are derived from published records and update automatically.
4. Check the preview, expand the project notes and confirm that the live website link opens the intended project. Verify the page at phone and desktop widths before publishing.

Only include verified claims. Do not add made-up performance metrics, testimonials, launch dates, or untested backend functionality. New records need no page component changes.

To hide a project temporarily, set `published: false` and redeploy. Its record and preview assets remain available for restoration, but it is omitted from the public showcase, index, count and page metadata. This is a display control, not access protection for static image files or the project's own website. Kingsford & Perla is currently unpublished at the owner's request.
