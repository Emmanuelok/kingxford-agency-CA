03 / LESS JARGON, MORE CLARITY

Plain words.
Better questions.

Contributions
The starting amount plus the money added each month in this model.
Compounding
Applying a rate to a balance that includes earlier modelled growth.
Nominal value
A number before adjusting for changes in purchasing power over time.
Assumption
An input chosen to explore a scenario. It is not a promise about the future.
